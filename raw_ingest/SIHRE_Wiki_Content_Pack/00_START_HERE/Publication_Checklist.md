# SIHRE Publication Checklist

## Before publishing

- [ ] Confirm title and canonical acronym.
- [ ] Verify all citations.
- [ ] Remove internal names and implementation details.
- [ ] Remove all domain-sensitive examples.
- [ ] Add version number.
- [ ] Add author name.
- [ ] Add license/copyright notice.
- [ ] Add suggested citation.
- [ ] Export clean PDF.
- [ ] Archive source Markdown.
- [ ] Create DOI record.
- [ ] Publish website page.
- [ ] Announce publicly.
- [ ] Record publication in disclosure log.

**SIHRE: Meta-Orchestrated Heterogeneous Reasoning for Adaptive Intelligence Under Non-Stationarity**

## Suggested versioning

- `v0.9` — pre-publication draft
- `v1.0` — first official public whitepaper
