# SIHRE Public / Private Boundary

## Public-safe

- SIHRE name and expansion
- General architectural framing
- Meta-orchestration concept
- Heterogeneous reasoning categories
- High-level evaluation principles
- Public-safe diagrams
- Non-sensitive examples
- Related work and prior art
- Limitations and non-goals

## Generalize before publishing

- Domain-specific evidence sources
- Domain-specific validation environments
- Domain-specific simulation concepts
- Domain-specific ontologies
- Domain-specific examples
- Performance language

## Keep private

- Exact modality count
- Internal system names
- Exact routing logic
- Orchestration weights
- Thresholds
- Training pipelines
- Data schemas
- Proprietary benchmarks
- Implementation-specific workflows
- Sensitive domain mechanics
