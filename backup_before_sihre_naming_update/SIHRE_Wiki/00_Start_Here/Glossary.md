# SIHRE Glossary

| Term | Meaning |
|---|---|
| SIHRE | Self-Improving Heterogeneous Reasoning Ensemble |
| Meta-orchestrator | The governance layer that routes, weights, challenges, escalates, suppresses, or promotes reasoning experts |
| Reasoning modality | A type of reasoning pathway, such as retrieval, graph reasoning, uncertainty estimation, or simulation |
| Expert | A module, model, tool, process, or reasoning component used by SIHRE |
| Non-stationarity | A condition where the data-generating environment changes over time |
| Drift | Change in inputs, outputs, relationships, labels, concepts, or reliability patterns |
| Persistent memory | A store of evidence, outcomes, provenance, and prior reasoning context |
| Verification layer | A layer that challenges or checks provisional conclusions |
| Simulation layer | A layer that explores alternative scenarios or stress conditions |
| Expert trust | Context-dependent estimate of how reliable a modality is under current conditions |
| Abstention | A decision to defer or request more evidence rather than force a conclusion |
| Self-improvement | Bounded updating of memory, trust, routing preferences, and research priorities |
| Domain adaptation | Adapting SIHRE to a domain through ontologies, evidence interfaces, metrics, and validation environments |
| Public-safe | Suitable for publication without revealing proprietary implementation details |
