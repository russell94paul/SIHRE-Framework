# SIHRE Layered Architecture

| Layer | Purpose | Public-safe examples |
|---|---|---|
| Evidence layer | Ingest observations and documents | sensor logs, records, events |
| Memory layer | Store context and prior outcomes | retrieved cases, provenance |
| Reasoning layer | Apply heterogeneous experts | predictive, causal, graph, retrieval |
| Verification layer | Challenge conclusions | critics, contradiction checks |
| Simulation layer | Test alternatives | scenario stress tests |
| Orchestration layer | Govern routing and trust | escalation, abstention, expert weighting |
| Adaptation layer | Improve over time | trust updates, memory updates |
| Interface layer | Communicate outputs | recommendation, uncertainty, deferral |
