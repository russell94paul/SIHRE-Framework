# Author Attribution Plan

## Goal

Attach SIHRE clearly to you as the creator.

## Tactics

- Use consistent name and title on all documents
- Add suggested citation to whitepaper
- Publish DOI record
- Add author page to website
- Announce on public channels
- Use same phrasing everywhere
- Keep a disclosure log
- Archive source files
- Preserve version history
