# SIHRE IP Strategy Memo

## Purpose

This memo tracks what should be protected, published, patented, trademarked, or kept as trade secret.

## Protection categories

| Category | Recommended treatment |
|---|---|
| SIHRE name | Trademark search / possible registration |
| Whitepaper | Copyright + DOI |
| High-level framework | Public publication |
| Exact implementation | Trade secret |
| Specific mechanisms | Patent attorney review |
| Diagrams | Copyright |
| Public vocabulary | Publish consistently |
| Control-plane software | Proprietary or open-core decision later |

## Possible patent families

- Meta-orchestrator routing mechanisms
- Expert trust update workflows
- Uncertainty-governed escalation
- Cross-modality verification loops
- Self-pruning expert topology
- Domain-conditioned reasoning governance
- Active-learning research prioritization
